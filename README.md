# FineJnag Vault

개인 프로젝트, 학습 기록, 일일 회고를 관리하는 Obsidian Vault입니다.

## 폴더 구성

- `00_Inbox`: 아직 분류하지 않은 메모
- `10_Dashboard`: 프로젝트 및 학습 현황
- `20_Projects`: 결과물이 있는 개인 프로젝트
- `30_Study`: 기술 및 주제별 학습 노트
- `40_Daily`: 일간 및 주간 기록
- `50_Resources`: 반복해서 참고할 자료
- `80_Templates`: Obsidian 문서 템플릿
- `90_Archive`: 종료한 프로젝트와 학습
- `Attachments`: 이미지와 첨부파일

## 사용 방법

이 저장소의 루트 폴더를 Obsidian에서 Vault로 엽니다. 새 메모는 먼저 `00_Inbox`에 작성하고, 내용이 정리되면 알맞은 프로젝트 또는 학습 폴더로 이동합니다.
