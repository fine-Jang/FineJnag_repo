# FineJnag Vault

개인 프로젝트, 학습 기록, 일일 회고를 관리하는 Obsidian Vault입니다.

현재는 사람이 직접 사용하는 단순한 구조를 유지합니다. AI 기능은 실제 필요가 확인될 때 한 단계씩 추가하며, 사용하지 않는 에이전트 규칙이나 자동화 스크립트는 미리 도입하지 않습니다.

## 폴더 구성

- `00_Inbox`: 아직 분류하지 않은 메모
- `10_Dashboard`: 프로젝트, 학습 현황 및 운영 로드맵
- `20_Projects`: 결과물이 있는 개인 프로젝트
- `30_Study`: 기술 및 주제별 학습 노트
- `40_Daily`: 일간 및 주간 기록
- `50_Resources`: 반복해서 참고할 자료
- `60_AI`: 향후 AI 기능을 단계별로 추가할 확장 영역
- `80_Templates`: Obsidian 문서 템플릿
- `90_Archive`: 종료한 프로젝트와 학습
- `Attachments`: 이미지와 첨부파일

## 사용 방법

이 저장소의 루트 폴더를 Obsidian에서 Vault로 엽니다. 새 메모는 먼저 `00_Inbox`에 작성하고, 내용이 정리되면 알맞은 프로젝트 또는 학습 폴더로 이동합니다.

## AI 기능 도입 원칙

1. 반복해서 필요한 기능인지 먼저 확인합니다.
2. 한 번에 한 기능만 추가합니다.
3. 사람이 작성한 노트 구조를 우선합니다.
4. 자동 생성 결과는 사용자가 확인한 뒤 Git에 반영합니다.
5. 원본 자료와 AI가 가공한 자료를 구분합니다.

구체적인 순서는 [[10_Dashboard/AI 기능 로드맵]]에서 관리합니다.
