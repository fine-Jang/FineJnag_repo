## 작업계획서에서 확인한 내용

- 표의 기본 열은 차수 / 구분 / 순번 / 내용 / 작업주체(R&R) / 소요기간입니다.
- 1차 사전작업, 2차 재구성, 3차 MTV 단계로 구성되어 있으며 기간은 각 1M, 합계 3M으로 표시되어 있습니다. 실제 달력 일정은 별도 확인합니다.
- 협조 사항은 행정처리(자산·구성·보안점검), 재활용 장비 3식 재배치(클라우드 전산실 → 3전산실), 상면·전기 포설입니다.
- 망별 기존 VMware 호스트 1식에 전체 VM을 집약한 뒤 나머지 장비를 재구성합니다.
- 신규 재활용 장비 배치는 외부 Master, 내부 Bastion·Master입니다. 신규 IP는 기존 네트워크 대역에 추가하는 계획입니다.
- EMC 스토리지 CSI 드라이버 설치 및 구성 단계가 명시되어 있습니다.
- MTV 준비는 Provider 등록 및 NetworkMap·StorageMap 구성입니다.
- VM 39식(업무망 26식 / 인터넷망 13식)을 업무 단위로 순차 이관합니다.
- 이관 후 잔여 VMware 호스트 2식을 Worker로 전환합니다.
- 원문의 작업주체는 운영자(관리원), VMware(기술지원), Redhat(기술지원), EMC(기술지원)입니다. 세부 담당 배정의 확정 여부는 확인이 필요합니다.

## 자료 수신 당시 기존 대화·V3와의 차이

| 항목 | 기존 대화 및 V3 | 제공 이미지 |
|---|---|---|
| AS-IS HV 수량 | 외부 3대 / 내부 2대 | 작업계획1은 외부 3대 / 내부 2대이나, 구성1·구성2 및 망연계1은 외부 2대 / 내부 3대로 표시 |
| Worker 번호 | 선구축 Worker2 / MTV 이후 HV#01 → Worker1 | 작업계획1 재구성 표는 선구축 Worker#01이며, 작업계획2 최종 표는 Worker#02를 추가 전환 대상으로 강조 |
| 기간 | MTV 예상 2개월, 적용 범위·전체 종료일 미정 | 1차·2차·3차 각 1M / 합계 3M |
| 보고서 형식 | 일반 보고서 장별 구성 | 차수·순번·내용·R&R·기간 중심의 상세 작업표 |

상세 구성도에는 서비스, 관리, 백업/NAS 네트워크 외에 WEB/WAS와 DB 영역, 보안 장비, 이중화 경로 및 망 연계가 표현되어 있습니다. 작은 글씨의 IP·자산번호·포트 표기는 판독 오류 방지를 위해 이 노트에 확정 전사하지 않았습니다.

### 후속 사용자 확인 및 반영

- DB 레거시 풀은 재구성 대상에서 제외합니다.
- Worker 번호는 제공 이미지 기준으로 변경하도록 사용자 확인을 받았습니다. Worker1을 선구축하고, MTV 이후 각 망 HV#01을 Worker2로 전환합니다.
- 해당 사항을 V3 HTML 및 사업 마크다운에 반영했습니다. 위 차이 표는 자료 수신 당시 비교 이력입니다.
- 후속 사용자 확인으로 실제 HV 수량은 외부망 2대·내부망 3대로 정정했습니다. V3와 사업 문서에 반영했습니다. 외부 Bastion 장비 출처 및 내부 잔여 HV의 역할은 추가 확인합니다.
