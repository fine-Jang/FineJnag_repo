Ⅰ. 사업 및 작업 개요

본 작업은 기존 VMware 환경의 가상머신을 OpenShift로 이관하고, 기존 장비와 재활용 서버를 활용하여 대상 인프라를 구성하는 것을 목적으로 합니다. 망별 HV#01은 VM 집약 및 MTV 이관 원본으로 유지하며, 대상 Worker1을 우선 구축합니다. 이관 완료 후 HV#01을 Worker2로 전환합니다.

이관 대상 VM39식외부망 13 / 내부망 26
재활용 서버 투입3대별도 확보 5대 중 2대 여유분
스토리지동일 EMC원본 FC LUN 유지 + CSI 대상 볼륨

VM 수량과 재활용 장비 수량은 기존 사업 기록 기준입니다. 호스트별 VM 배치 및 수행 시점의 실제 자원 현황은 착수 전 대조합니다.

2. 동일 EMC 스토리지 사용 계획 — 이관 기간

CSI는 볼륨 할당·연동 방식입니다. FC 등 실제 데이터 연결 프로토콜은 EMC 모델과 지원 드라이버를 확인한 후 확정합니다. NAS/BK망과 VM 데이터스토어의 FC 경로는 구분합니다. 기존 NFS 언급은 NAS·백업 용도 등 적용 범위를 별도로 확인하며, VM 데이터스토어 방식으로 표기하지 않습니다.

3. 스토리지 용량 산정 초안

동일 EMC에서 기존 VMware 데이터스토어를 유지하면서 MTV 대상 볼륨을 추가 확보합니다. 원본 데이터스토어와 대상 볼륨을 별도로 관리하며, 이관 및 원본 보관 기간에는 두 영역을 동시에 수용해야 합니다. 풀별 잔여 용량과 망별 VM 설정·사용 용량을 확보한 뒤 산정합니다.

사업 관련 동시 확보 공간 = 기존 VMware 데이터스토어 유지분 + MTV 대상 볼륨 + 추가 공간·운영 여유
추가 필요 공간 = MTV 대상 볼륨 + 오버헤드·플랫폼 공간 + 임시·스냅샷 공간 + 운영 여유
부족분 = max(0, 추가 필요 공간 − 사업에 할당 가능한 실제 잔여 용량)

산정식은 초기 검토 기준이며, 실제 필요 용량은 자원 현황 확보 후 확정합니다. 사업에 할당 가능한 실제 잔여 용량은 원본 데이터스토어 유지분을 제외한 값입니다. 원본 유지분은 추가 필요 공간에 중복 가산하지 않으며, 원본 삭제로 회수할 용량도 사전에 가용 공간으로 계산하지 않습니다. 같은 풀을 공유하는 경우 여유 공간을 망별로 중복 계산하지 않습니다.
