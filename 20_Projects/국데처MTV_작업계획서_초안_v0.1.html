01. 작업 개요

기존 VMware 환경의 VM을 OpenShift로 이관한다. 망별 HV#01에 VM을 집약해 MTV 이관 원본을 유지하고, 다른 기존 장비와 재활용 서버로 대상 인프라를 먼저 구성한다. MTV 완료 후 HV#01을 Worker1으로 전환한다.

VM 수량과 재활용 장비 수량은 기존 사업 기록 기준. 호스트별 VM 배치 및 수행 시점의 실제 자원 현황은 착수 전 대조한다.

02. AS-IS / TO-BE 비교 구성도

서비스망관리망NAS / BK망녹색 영역: VM 풀

외부망 — 기존 HV 3대

내부망 — 기존 HV 2대

TO-BE는 MTV 완료 후의 최종 역할 구성이다. 이관 진행 중에는 Worker2만 먼저 구성하고, HV#01은 VMware 원본으로 남긴다. Master 박스는 역할을 표현하며 실제 물리·가상 노드 수나 HA 구성을 확정한 것이 아니다.

선은 논리적 망 연결이다. 물리 회선 수·스위치·Bond 방식 및 VM NIC/NAD/브리지 상세는 미확정이다. Master·Bastion의 연결망은 추가 설계 후 표시한다. NFS의 망별 공유 여부와 접속 경로도 추가 확인한다. 관리망은 BMC/OOB를 의미하지 않는다.

신규 서버에 3개 망을 모두 연결한다는 의미가 아니다. 실제 연결망 확정 후 비대상 셀은 ‘해당 없음’으로 정리한다. 기존 IP는 원 장비에서 해제한 뒤 전환 장비에 적용해 중복 사용을 방지한다.

스토리지 용량 산정 초안

원본 VM을 보존하는 기간 동안 대상 VM 디스크와 이관 중 임시 공간을 함께 수용할 수 있는지 확인한다. 풀별 잔여 용량과 망별 VM 설정·사용 용량을 확보한 뒤 산정한다.

추가 필요 공간 = 대상 디스크 + 오버헤드·플랫폼 공간 + 임시·스냅샷 공간 + 운영 여유
부족분 = max(0, 추가 필요 공간 − 사업에 할당 가능한 실제 잔여 용량)

협의용 산정식이며 확정 용량이 아니다. 원본은 잔여 용량 산정에 이미 반영하므로 중복 가산하지 않는다. 같은 풀을 공유하는 경우 여유 공간을 망별로 중복 계산하지 않는다.

05. 단계별 작업 절차 — 초안

단계작업 내용진행 전 확인 / 완료 기준
1. 현황·백업 확보HV·VM·네트워크·NFS 현황 및 설정 기록, 복구 가능한 백업 확보백업 복구 방식, 콘솔 접근, 망별 HV#01 수용 자원 확인
2. VMware VM 집약외부 VM 13식·내부 VM 26식을 각 망 HV#01로 집약VM 이동 방식 확정, 서비스 정상 확인, 나머지 HV의 VM 잔존 여부 확인
3. 장비 재구성외부 기존 HV 1대 Bastion, 1대 Worker2 구성. 내부 HV#02 Worker2 구성외부 HV 번호별 배정 확정, IP 중복 방지, 재구성 전 데이터·설정 보존
4. 신규 인프라 구축재활용 서버로 외부 Master, 내부 Master·Bastion 구성Master 실제 구성·설치 방식·호환 버전 및 신규 IP 확정
5. OpenShift 기반 검증클러스터·가상화 기능·네트워크·NFS 스토리지 구성 및 검증Worker2 단독 운영 기간의 자원 수용 여부, NFS 읽기·쓰기 및 VM 디스크 기능 확인
6. MTV 준비·시험 이관소스·대상 연결 구성, 망별 대표 VM 선정, 시험 이관MTV 버전·이관 방식 확정, 연결·권한·인증서·필요 통신 확인, 시험 결과 기록
7. 회차별 본 이관회차별 대상 선정 → 사전 검사 → 이관 → 네트워크·서비스 전환 → 검증동일 서비스 원본·대상의 동시 활성화 방지, 회차별 성공·실패·재작업 기록
8. HV#01 전환 판단대상 서비스 검증, 원본 보관 및 복구 조건 확인원본 HV를 재구성해도 되는 시점 명시, 백업 및 데이터 복구 경로 확보
9. Worker1 추가각 망 HV#01 재구성 → Worker1 편입, 기존 IP 재사용노드·네트워크·NFS 정상 확인, VM 배치·이동 검증 범위 협의
10. 완료 기록최종 구성·IP·VM 이관 결과 및 잔여 작업 정리합의된 검수 항목 충족, 구성도·작업 결과서 갱신

3~5단계의 세부 순서는 실제 설치 방식과 Master 구성에 맞춰 조정한다. 작업 명령·수행일·소요 시간은 아직 확정하지 않았으며 본 표는 실행 전 검토용이다.
