# 국데처 MTV 설계 및 작업계획서 v2.9 릴리스 기록

고객 제출용 작업계획서 v2.8([수정안](국데처MTV_v2.8_수정안.md))의 장 구성을 유지하고, 내용은 [구축설계서 v1.6](SGIS_OCP_BuildDesign_v1.6_notes.md) 기준으로 맞춘 버전입니다. 반영본은 [SGIS_MTV_WorkPlan_v2.9.html](SGIS_MTV_WorkPlan_v2.9.html)이며, v2.8은 그대로 둡니다.

## 결정

- 장 구성: v2.8 그대로(01 개요 ~ 07 일정·확정 항목), 내용은 구축설계서 v1.6 기준.
- 스토리지: 스토리지 엔지니어에게 요청할 작업만 남김.
- VM: 현행 VM 39식 전체를 하이퍼바이저별로 표시하고 서비스 VM · VMware DNS VM · vCenter/vCLS를 구분.
- 고객 문서에서 제외: IP 값·IP 기입표, 설치 체크리스트, bond·bridge 이름 확정 항목, 서버별 물리 인터페이스 표.

## 변경 사항

1. **표지**: 제목 "인프라 전환 설계 및 MTV 작업계획서", 버전 태그 "VERSION 2.9 / 고객 제출용 · 구축설계서 v1.6 반영", 수정일 2026.10.14.
2. **VM 수량 정정**: 업무 VM 12/25 → 11/24(실사 정정, 구축설계서 v1.2와 동일). 03 표·05 10단계 반영.
3. **01 개요를 구축설계서 v1.6 구성으로 교체**: 소개 문단 아래 숫자 카드 4개 → ① 현재 VMware 구성 그림 → ② 현행 VM · 이관 대상 — 하이퍼바이저별 → ③ 구축할 OpenShift 인프라 그림 + 적용 버전 → 계획 기준 표(v2.8).
   - ② 표(신규): 망 · HV별 서비스 VM(수량·OS·vCPU/메모리·데이터스토어), VMware DNS VM, vCenter·vCLS, 전환 후 역할. 망별 소계(외부 13식 · 내부 26식)와 합계 39식(서비스 35 · DNS 2 · vCenter 2).
4. **02 구성도를 구축설계서 v1.6 그림으로 교체**: v2.8의 망별 AS-IS/TO-BE SVG 2개 → v1.6 "망별 장비 재구성 (AS-IS → TO-BE)"(외부망·내부망 재구성 그림 + 단계 카드 1~5). 문서 스타일은 v1.6 스타일(v2.8 규칙 포함)로 교체.
5. **이관 방식 VDDK로 통일**: Copy Offload · Skip VDDK · "사용 확정 시" 문구 삭제(01 표, 04, 05 단계·UPI 절차·전환 순서, 06 위험, 07 일정·확정 항목). 04장에 "이관 방식 — VDDK" 표(복사 경로·준비·콜드/웜·Plan 단위·IP 유지·Windows VM) 추가, 전송 시간 표는 유지.
6. **스토리지**: 스토리지 매핑 그림·표, 이관 방식 비교표, 스토리지 연결 준비, 동일 EMC 사용 계획 그림, 용량 산정 삭제. PowerMax CSI·StorageClass·멀티패스 문구 전부 삭제. "스토리지 엔지니어 요청 작업" 표 신설:
   - 11월 재구성 전: 외부 HV#02, 내부 HV#01·HV#03 VMFS LUN 매핑 해제.
   - 이관·보관 기간: 원본(외부 HV#01·내부 HV#02) LUN·데이터스토어 유지.
   - Worker2 전환 전: 외부 HV#01·내부 HV#02 LUN 매핑 해제.
   - 보관·원복 기준 충족 후: 원본 LUN·데이터스토어 회수(별도 판단).
7. **04 네트워크**: 전체 구성도·VM 네트워크 매핑 그림을 구축설계서 v1.6 그림으로 교체(브리지 br0, Bastion NAS/BK 포설, NTP, 포트 속도 10G/IPMI 1G). 노드별 포트 표: Bastion 양 망 NAS/BK 2포트 신규 포설(etcd 백업), Master KVM은 관리망만. Bastion 서비스에 NTP 123/UDP 추가. IP 할당 계획 제목에 "신규 IP 망별 7개 (관리망 6 · nasbak 1)" — 값은 넣지 않음.
8. **03 장비 활용**: Worker1 수용 용량 표(구축설계서 v1.6) 추가.
9. **06·07**: etcd 백업은 Bastion이 NAS/BK망으로 보관하도록 정정. 위험 "VDDK 전송 속도"로 교체, "스토리지 모델·CSI" 행 삭제, Worker1 단독 운영에 내부망 메모리 약 82% 추가. 확정 항목: 스토리지·VMware·네트워크 담당 내용을 v1.6 기준으로 갱신.
10. 꼬리말: Dell CSM 카탈로그 링크 삭제, 작성 근거에 구축설계서 v1.6 추가.

## 검증

- 그림 밖 본문과 그림 안에 PowerMax · CSI · Copy Offload · Skip VDDK · 멀티패스 · "사용 확정" · 업무 VM 12/25 문구가 남지 않음을 스크립트로 확인.
- 브라우저 렌더링으로 01장 개요 그림·VM 표, 02장 장비 재구성 그림, 04장 구성도·포트 표·VDDK 표·스토리지 요청 작업 표 확인.
- 문서에 IP 주소 없음.
