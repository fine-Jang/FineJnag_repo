# 국데처 SGIS OpenShift 구축설계서 v1.3 릴리스 기록

v1.2([릴리스 기록](SGIS_OCP_BuildDesign_v1.2_notes.md))의 03~09장을 축약한 버전입니다. 반영본은 [SGIS_OCP_BuildDesign_v1.3.html](SGIS_OCP_BuildDesign_v1.3.html)이며, v1.2는 그대로 둡니다. 다른 아키텍처 설계서(ocp418-podonly-topology v0.5)의 형식을 참고했습니다.

## 작성 기준

- 그림 + 짧은 설명(2~3줄) + **설계 항목 표**(항목 · 내용 · 상태)로 정리. 상태는 확정 / 결정 필요 / 확인 필요.
- 중복 표 통합, 근거가 확인되지 않은 가정 문장은 본문에서 빼고 **확인 필요 사항**으로 이동.
- 01·02장은 유지(수치·문구 정정만).

## 장별 변경

| 03 | 실사 문단, 망 정의, 노드별 포트, 클러스터 파라미터, 호스트명·IP 할당표, 신규 IP 소요, DNS 레코드, Bastion 서비스, NTP 문단, 방화벽, NMState·NAD, VM 네트워크 매핑 그림·표 | 그림 1(전체 구성도) + 설계 항목 12행 + 그림 2(VM 네트워크 매핑) + **서버별 IP 기입표**(빈칸 양식, 망별 6행) + 방화벽 신청 2건 + 확인 필요 사항 7건 |
| 04 | 장비 사양, VM·노드 사양, 수용 용량 표·산식·설명 5개 | 장비·노드 사양 표 1개 + Worker1 수용 용량 표 + 설명 2줄 |

## 수치

- 표 28개 → 15개, SVG 4개 → 3개(전체 구성도, VM 네트워크 매핑, 스토리지 매핑 유지 · 동일 EMC 사용 계획 삭제).

## 검증

- 구성도 SVG 글자 넘침 검사 결과 넘침 없음.
- 브라우저 렌더링으로 03장 설계 항목·서버별 IP 기입표·확인 필요 사항 확인.
