# 국데처 SGIS OpenShift 전환 구축 계획 v3.0pt 릴리스 기록

고객사 서버 운영자용 PowerPoint(16:9, 17장)입니다. 내용 근거는 [구축설계서 v1.8](SGIS_OCP_BuildDesign_v1.8_notes.md)과 [작업계획서 v2.9](SGIS_MTV_WorkPlan_v2.9_notes.md)의 일정입니다. 반영본은 SGIS_MTV_WorkPlan_v3.0pt.pptx이며, v2.9pt는 그대로 둡니다.

## 결정

- 대상: OpenShift를 처음 접하는 고객사 서버 운영자.
- 그림 위주 구성. 그림은 PowerPoint 도형으로 그림(수정 가능).
- 슬라이드 아래쪽에 "※ 용어 : 설명" 형식으로 용어 설명, 마지막 장에 용어 정리.
- 협의 항목(구축설계서 08장 요청·협의 사항, TBD)은 넣지 않음. 고객사가 할 일은 "사전 준비 ①~⑤"로 정리하고 별도 강조는 하지 않음.
- 문체: 대제목·소제목은 짧은 명사형. 설명·용어 풀이는 "~다"로 맺지 않고 단어로 끝냄("~할 때 사용하는 포트", "~하는 작업", "~의 단위"). "~해 주세요" 같은 요청형과 안내성 사족은 쓰지 않음.
- 표지: 화면을 반으로 나눠 왼쪽에 서버·데이터 이미지, 오른쪽 흰 바탕에 로고·제목 배치. 슬라이드에 릴리스 버전·근거 문서 표기 없음(표지 날짜 2026.10, 꼬리말 "국가데이터처 SGIS · OpenShift 전환 구축").
- IP 값은 넣지 않고 개수만 표시. VDDK는 언급하지 않고 "네트워크 복사"로 표현.
- DNS VM: 원본 HV로 이동(vMotion) 후 유지, MTV 완료 후 삭제(구축설계서 v1.8 기준).
- 고객 검토 반영(2026-10-15):
  - VMware Tools는 설치하지 않음. 이관 후 VM 안에서 IP를 직접 설정(IP 유지 조건 없음).
  - vCenter·원본 HV는 MTV 완료까지 유지, 정리는 MTV 완료 후. 3단계 HV 정리 = 재구성 대상 HV의 VM(DNS VM 포함)을 원본 HV 1대로 모두 이동 → 호스트 제거.
  - LUN 매핑 해제는 다루지 않고, OpenShift 노드(Worker1·2)에 이관 VM 디스크용 FC LUN 매핑을 사전 준비로 둠.
  - OpenShift 노드 → vCenter·ESXi(443·902)는 같은 관리망(L3) 통신이라 방화벽 신청 대상 아님.
  - bootstrap IP는 master 구성 완료 후 반납. Master VM 이름은 master-1·2·3.
  - Worker1·2 모두 "재구성"으로 표현 통일(Worker2: MTV 후 재구성). 이관 순서는 "외부망 먼저 작업"으로 명시.
