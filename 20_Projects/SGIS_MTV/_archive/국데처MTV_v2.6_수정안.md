# 국데처 MTV 작업계획서 v2.6 수정안

V2.5 작업계획서를 기준으로 v2.2에서 빠졌던 동일 EMC 스토리지 사용 계획 그림을 복원한 릴리스 기록입니다. 반영본은 [SGIS_MTV_WorkPlan_v2.6.html](SGIS_MTV_WorkPlan_v2.6.html)입니다. 아래 항목 외의 내용은 v2.5와 같습니다.

## v2.6 반영 사항

1. **동일 EMC 스토리지 사용 계획 — 이관 기간 그림 복원 (04장)**
   - v2.1에 있던 그림을 v2.2에서 스토리지 매핑 그림으로 대체하며 뺐던 것을 다시 넣었습니다. 위치는 `스토리지 용량 산정` 바로 위이며, 약 74.7TB 추가 용량의 근거 그림입니다.
   - 실사 값으로 갱신: 원본 HV(외부 HV#01·내부 HV#02), 원본 VMFS6 74.7TB(외부 1개 12.4TB·내부 3개 62.3TB), 대상 PowerMax CSI·RWX Block StorageClass, 대상 볼륨 약 74.7TB 이상 추가, FC 연결과 Worker 호스트 등록·마스킹 재확인.
   - 기간 표시 추가: 11월 CSI 구성·시험 볼륨 → 12월 본 이관(잠정) → 보관·원복 기준 충족 후 원본 LUN 회수(Worker2 전환과 별도 판단).

2. **스토리지 매핑 그림 중복 정리 (04장)**
   - 오른쪽 아래 `Dell EMC 배열 (SYMMETRIX)` 상자에서 동시 확보·74.7TB 문구를 빼고 `PowerMax 세대 · CSI의 OCP 4.22 지원 확인`만 남겼습니다. 용량 내용은 복원한 그림이 담당합니다.

3. **전체 구성도 — 한 망 기준 일반화 (04장)**
   - 한 망 예시 그림이 망별 장비와 혼동되지 않도록 노드 상자의 장비 배정·재구성·전환 문구(TNS-2100, HV 번호)와 TNS-2100 강조 배지·테두리·범례를 뺐습니다.
   - 소스 VMware 상자는 `원본 HV (업무 VM 위치)`, EMC 상자는 `원본: VMFS6 데이터스토어 (FC LUN)`로 일반화했습니다. 대수·용량은 01장과 스토리지 부분을 따릅니다.
   - 외부 Master의 NAS/BK 추가 포설은 실제 구성 차이이므로 `NAS/BK ×2 (외부망만)`으로 조건을 밝혀 남겼습니다(용도는 그림 각주의 etcd 백업).
   - 그림 아래 설명에서 장비 배정 문장을 빼고 `망별 장비 배정은 03장을 따릅니다`로 바꿨습니다.

4. **검토 지적 사항 정정**
   - 04장 IP 할당 계획 표: 중복된 `공통` 행 1개를 삭제하고, 누락된 `</thead><tbody>`를 넣어 데이터 행이 인쇄 시 반복 헤더로 찍히지 않게 했습니다.
   - 05장 1단계: 07장 1차 사전작업과 맞추어 단계명을 `사전작업·현황·백업 확보`로 바꾸고, 행정작업·장비 재배치(TNS-2100 랙 설치)·전기 포설·관리·IPMI 포트 결선과 완료 기준 `TNS-2100 전원·관리 포트 연결 확인`을 추가했습니다.
   - `국데터 SGIS 구성` → `국데처 SGIS 구성` 오타 정정(04장·05장 2곳, 원본 `국데처MTV 사업.md` 109행).
   - 04장 스토리지 연결 준비 `Worker 전환 HV` 대상에서 Master 호스트인 내부 HV#03을 뺐습니다(외부 HV#02·HV#01, 내부 HV#01·HV#02).

5. **VM 네트워크 매핑 그림에서 관리망 bond0 제외 (04장)**
   - VM이 쓰는 망만 보이도록 bond0 상자·스위치 `태그 없음` 상자·화살표와 노드 자체 통신 설명 2줄을 뺐습니다.
   - 그림 아래 설명에 `관리망 bond0은 노드 자체 통신용으로 VM에 연결하지 않으므로 이 그림에서 제외(노드별 포트·망 구성 표 참조)`를 추가했습니다.

6. **버전·수정일**
   - 표지 `VERSION 2.6`, 수정일 2026.10.13.
