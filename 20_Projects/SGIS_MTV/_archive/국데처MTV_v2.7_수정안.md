# 국데처 MTV 작업계획서 v2.7 수정안

V2.6 작업계획서를 기준으로 스토리지 용어를 통일하고 구성도 글자 넘침을 정리한 릴리스 기록입니다. 반영본은 [SGIS_MTV_WorkPlan_v2.7.html](SGIS_MTV_WorkPlan_v2.7.html)입니다. 아래 항목 외의 내용은 v2.6과 같습니다.

## v2.7 반영 사항

1. **용어 통일: 배열 → 스토리지 (전 장)**
   - 현장에서 쓰지 않는 직역어 `배열`(storage array)을 `스토리지`로 통일했습니다(본문·표·구성도 23곳, 그림 설명 1곳).
   - 주요 치환: `Dell EMC 배열` → `Dell EMC 스토리지`, `배열 세대/모델(PowerMax 세대)` → `스토리지 모델(PowerMax 여부)`, `배열 내부 XCOPY` → `스토리지 내부 복제(XCOPY)`, `배열 관리 주소·계정` → `스토리지 관리(Unisphere) 주소·계정`, `배열 호스트 등록·마스킹` → `스토리지 호스트 등록·마스킹`, `배열 풀/잔여 용량` → `스토리지 풀/잔여 용량`.

2. **구성도 글자 넘침 정리 (04장)**
   - 모든 구성도의 SVG 글자를 상자·그림 경계와 대조 검사했습니다. 넘침은 전체 구성도 맨 아래 각주 1줄(그림 폭 1400 초과)뿐이었습니다.
   - 해당 각주를 두 줄로 나누고 그림 높이를 745 → 770으로 늘렸습니다. 재검사 결과 넘침 없음.

3. **버전·수정일**
   - 표지 `VERSION 2.7`, 수정일 2026.10.13.
