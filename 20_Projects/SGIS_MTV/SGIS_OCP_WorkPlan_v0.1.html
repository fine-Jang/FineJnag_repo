02. Bastion 구축

시기 · 11월(2차) · HV 작업과 무관하게 먼저담당 · 구축팀OS · RHEL 9.8

2-1. OS · 네트워크

예시# 관리망 bond0 (active-backup)
nmcli con add type bond con-name bond0 ifname bond0 bond.options "mode=active-backup,miimon=100"
nmcli con add type ethernet con-name bond0-p1 ifname <관리 포트1> master bond0
nmcli con add type ethernet con-name bond0-p2 ifname <관리 포트2> master bond0
nmcli con mod bond0 ipv4.method manual ipv4.addresses <Bastion IP>/<prefix> ipv4.gateway <관리망 GW> ipv4.dns 127.0.0.1
nmcli con up bond0

# nasbak bond2 (etcd 백업용 · 기본 GW 없음)
nmcli con add type bond con-name bond2 ifname bond2 bond.options "mode=active-backup,miimon=100"
nmcli con add type ethernet con-name bond2-p1 ifname <NAS/BK 포트1> master bond2
nmcli con add type ethernet con-name bond2-p2 ifname <NAS/BK 포트2> master bond2
nmcli con mod bond2 ipv4.method manual ipv4.addresses <Bastion nasbak IP>/<prefix> ipv4.never-default yes
nmcli con up bond2

hostnamectl set-hostname <bastion FQDN>

확인: ip -br a, cat /proc/net/bonding/bond0 활성 포트 · 관리망 GW ping · 백업스토리지 ping. nasbak VLAN 태깅 방식(access/trunk) TBD

2-4. 부하분산 (HAProxy)

예시# /etc/haproxy/haproxy.cfg (mode tcp)

04. Master 구성 · 클러스터 설치

시기 · 11월담당 · 구축팀대상 · 외부 TNS-2100 #B · 내부 HV#03

4-1. KVM 호스트 (RHEL 9.8)

예시# bond0: 호스트 원격접속 (IP)
nmcli con add type bond con-name bond0 ifname bond0 bond.options "mode=active-backup,miimon=100"
nmcli con add type ethernet ifname <관리 포트1> master bond0
nmcli con add type ethernet ifname <관리 포트2> master bond0
nmcli con mod bond0 ipv4.method manual ipv4.addresses <KVM 호스트 IP>/<prefix> ipv4.gateway <관리망 GW> ipv4.dns <Bastion IP>

# bond1 → br0: VM 연결용 (IP 없음)
nmcli con add type bridge con-name br0 ifname br0 ipv4.method disabled ipv6.method disabled stp no
nmcli con add type bond con-name bond1 ifname bond1 master br0 bond.options "mode=active-backup,miimon=100"
nmcli con add type ethernet ifname <관리 포트3> master bond1
nmcli con add type ethernet ifname <관리 포트4> master bond1
nmcli con up bond0; nmcli con up br0

dnf install -y qemu-kvm libvirt virt-install
systemctl enable --now libvirtd
# chrony: server <Bastion IP> iburst

확인: virsh list --all, bridge link에 bond1 → br0, br0에 IP 없음

4-2. install-config · ignition 생성 (Bastion)

예시# install-config.yaml 주요 값
baseDomain: <base domain>
metadata: { name: <클러스터명> }
controlPlane: { name: master, replicas: 3 }
compute: [ { name: worker, replicas: 0 } ]
networking:
  networkType: OVNKubernetes
  machineNetwork: [ { cidr: <관리망 CIDR> } ]
  clusterNetwork: [ { cidr: 10.128.0.0/14, hostPrefix: 23 } ]   # 사내 대역 중복 확인
  serviceNetwork: [ 172.30.0.0/16 ]
platform: { none: {} }
pullSecret: '<미러 레지스트리 인증>'
sshKey: '<Bastion 공개키>'
additionalTrustBundle: |   # 미러 레지스트리 CA
imageDigestSources:        # oc-mirror 결과에서 복사

mkdir ~/install && cp install-config.yaml ~/install/ && cp install-config.yaml ~/install-config.bak
openshift-install create manifests --dir ~/install
# Master에 업무 Pod가 올라가지 않도록
sed -i 's/mastersSchedulable: true/mastersSchedulable: false/' ~/install/manifests/cluster-scheduler-02-config.yml
# 노드 chrony → Bastion (butane으로 MachineConfig 생성 후 openshift/ 에 추가)
openshift-install create ignition-configs --dir ~/install
cp ~/install/*.ign /var/www/html/ && chmod 644 /var/www/html/*.ign

ignition 인증서는 24시간 안에 설치를 마칩니다. 넘기면 install-config.bak으로 다시 생성합니다.

4-3. bootstrap · master VM 생성 (KVM 호스트)

예시# bootstrap 4 vCPU · 16GB · 100GB / master 8 vCPU · 32GB · 120GB
virt-install --name bootstrap --vcpus 4 --memory 16384 --disk size=100,bus=virtio \
  --network bridge=br0,model=virtio --cdrom /var/lib/libvirt/images/rhcos-live.iso \
  --os-variant rhel9.4 --graphics vnc --noautoconsole
for n in 1 2 3; do
  virt-install --name master-$n --vcpus 8 --memory 32768 --disk size=120,bus=virtio \
    --network bridge=br0,model=virtio --cdrom /var/lib/libvirt/images/rhcos-live.iso \
    --os-variant rhel9.4 --graphics vnc --noautoconsole
done
