# SGIS MTV 이관 작업 가이드 v1.1 — 변경 사항

- 기준: v1.0 (2026.11.23) → v1.1 (2026.11.24)
- 파일: `SGIS_MTV_WorkGuide_v1.1.html`

## 코드 블록 구분
- 실행 명령: 네이비 머리표, 연회색 바탕
- 확인 명령: 녹색 머리표, 연녹색 바탕
- 파일 내용(vi로 직접 작성): 황색 머리표 「vi로 작성 / 파일 내용」, 크림색 바탕 (기존 「코드」 블록 10개 포함, 12개)
- 명령이 만드는 파일(`cat > 파일 <<EOF` ~ `EOF`): 명령 안 해당 구간을 황색 바탕으로 표시, 시작 줄에 「▼ 파일 생성: 경로」, 끝 줄에 「▲ 파일 끝」, 머리표에 「파일 생성 포함」 (24곳)
- 직접 채울 값 `<…>`: 빨간 글자
- ocp.env 변수 `${VAR}`: 파란 글자
- 주석 `#`: 회색 기울임
- 표식은 화면 표시용이고 명령 문자열은 v1.0과 같음 (복사 시 그대로)
- 문서 안내에 「코드 블록 구분」 범례 추가

## 단계 체크
- 명령 블록마다 단계 머리줄(번호 · 제목 · 실행/확인/파일 구분) + 체크 칸 (174단계)
- 절(3-1 등)·장 첫머리에 체크리스트(진행 수·진행 막대, 단계로 이동 링크) 19개
- 왼쪽 목차에 장·절별 진행 수(완료 시 ✓)
- 상단: 전체 진행 막대, 「다음 미완료 단계」, 「체크 초기화」
- 체크 상태는 브라우저 localStorage에 저장 (같은 PC·같은 브라우저에서만 유지)
