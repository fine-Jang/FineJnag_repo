# 프로젝트 현황

## 진행 중

- [[20_Projects/SGIS_MTV/국데처MTV 사업|국데처MTV 사업]] — 국가데이터처 SGIS 오픈플랫폼 VMware → OpenShift(OVE) 전환 및 MTV 이관. 운영 서버 5식·VM 39식, **2021년 도입 S존 TNS-2100 총 5대 확정(구성 투입 예정 3대·여유분 2대)**. 현재 작업 협의·현황 파악 중.

다음 작업: 업무망 VM 26식·인터넷망 VM 13식을 망별 VMware 호스트 1대씩으로 집약해 MTV 원본 호스트 총 2대를 유지하고, 나머지 기존 서버 3대를 재구성용으로 확보할 계획.

재활용 TNS-2100 서버당 사양: **CPU 36 Core / 메모리 576GB(48GB × 12) / NIC 포트 5개**.

예상 일정(2026-09-30 기준): **10월** 행정작업·장비 재배치 후 전기 포설 등 사전 준비, **11월부터 본 작업 착수 예정**. MTV 예상 2개월의 상세 적용 일정과 완료일은 미확정.

최종 장비 구성은 사업 문서의 TO-BE 표를 기준으로 관리. 현재 주요 확인 항목은 **유휴 리소스 수치 확보**, **EMC 모델·자원 확인 및 MTV 증설량 개략 산정**, **MTV 일정별 대상 선정**.

버전 기준: **OCP 4.22 / Master·Worker는 RHEL 9.8 기반 RHCOS**, Bastion은 **RHEL 9.8**. 공식 릴리스 제공 여부는 확인했으며, 11월 구축용 세부 버전·장비 및 MTV·CSI 호환 조합은 확인 필요.

현재 이슈: 재활용 **TNS-2100의 RHEL 9.8 및 OCP 4.22 호환성** 확인 필요. 실제 장착 드라이버·펌웨어 지원 범위 검증 대기. eSlim은 대상에서 제외.
