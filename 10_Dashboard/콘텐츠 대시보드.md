## Git 커밋 내역

Obsidian Git의 History View에서 커밋 날짜, 메시지, 변경 파일을 확인할 수 있습니다.

1. `Ctrl + P`로 명령 팔레트를 엽니다.
2. `Git: Open history view`를 실행합니다.
3. 원하는 커밋을 선택해 변경 파일과 차이를 확인합니다.

> [!note]
> Obsidian Bases는 Markdown 파일과 Properties를 조회하지만 `.git` 커밋 로그를 직접 읽지는 않습니다. 커밋 내역은 Git 플러그인의 History View를 사용합니다.
