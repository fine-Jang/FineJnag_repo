# AI 기능 로드맵

AI 기능은 실제 사용 흐름이 자리 잡은 뒤 아래 순서로 하나씩 추가합니다.

## 1. Obsidian 기본 운영

- [ ] PC에 저장소 복제
- [ ] 저장소 루트를 Obsidian Vault로 열기
- [ ] 프로젝트·스터디·일일 노트 작성 흐름 정착
- [ ] Git pull, commit, push 흐름 정착

## 2. 일일 학습일지 자동화

- [ ] 프로젝트의 당일 Git 커밋 수집
- [ ] 변경 내용을 GPT로 요약
- [ ] `40_Daily/YYYY/MM/YYYY-MM-DD.md` 생성
- [ ] 사용자 확인 후 commit

## 3. 자료 수집

- [ ] Telegram 파일·메모 업로드
- [ ] 원본 자료 저장 영역 구성
- [ ] AI 요약을 `30_Study` 또는 `50_Resources`에 저장

## 4. 프로젝트 플래너

- [ ] 목표와 완료 조건 관리
- [ ] 프로젝트별 할 일 생성
- [ ] 커밋 기반 진행 상황 계산
- [ ] 미완료 일정 재조정

## 5. AI 작업 맥락

- [ ] `AGENTS.md` 도입
- [ ] 중요 문서 색인 도입
- [ ] 작업 로그 도입
- [ ] `save`, `query` 규칙 정의

## 6. 의사결정·실패 기록

- [ ] 의사결정과 근거 기록
- [ ] 실패 사례와 재발 방지 정보 기록

## 7. Telegram 봇

- [ ] 오늘 계획 조회
- [ ] 공부 시작·종료 기록
- [ ] 파일 업로드
- [ ] 일일 회고
- [ ] Git 커밋 승인

## 운영 원칙

- 현재 단계가 안정화되기 전에는 다음 자동화를 추가하지 않습니다.
- 자동 생성 결과는 사용자가 검토한 후 저장합니다.
- API 키, 토큰, SSH 개인키는 Vault에 저장하지 않습니다.
