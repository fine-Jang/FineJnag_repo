4-4. 인증서 생성 + Quay 설치 스크립트

자체 Root CA(10년)를 만들고 그 CA로 Quay 서버 인증서를 서명한 뒤 mirror-registry를 설치합니다.

install_quay.sh 
#!/bin/bash
set -euo pipefail

REG_HOME="/opt/openshift/mirror-registry"
REG_URL="init-quay.ocp.aon.cloud"
REG_PORT="8443"

INIT_USER="admin"
INIT_PASSWORD='<Quay 암호>'

QUAY_HOSTNAME="${REG_URL}:${REG_PORT}"
QUAY_ROOT="${REG_HOME}/quay"
QUAY_STORAGE="${REG_HOME}/quay/quaystorage"

CERT_DIR="${QUAY_ROOT}/cert.d"
CA_DIR="${QUAY_ROOT}/ca"
ROOT_CA_KEY="${CA_DIR}/aon-root-ca.key"
ROOT_CA_CRT="${CA_DIR}/aon-root-ca.crt"
SERVER_KEY="${CERT_DIR}/${REG_URL}.key"
SERVER_CSR="${CERT_DIR}/${REG_URL}.csr"
SERVER_CRT="${CERT_DIR}/${REG_URL}.crt"
SERVER_EXT="${CERT_DIR}/${REG_URL}.ext"

mkdir -p "${QUAY_ROOT}"/{data,cert.d,pgstorage,quaystorage,ca}

echo "### 1. Root CA 개인키"
openssl genrsa -out "${ROOT_CA_KEY}" 4096

echo "### 2. Root CA 인증서 (10년)"
openssl req -x509 -new -nodes -key "${ROOT_CA_KEY}" -sha256 -days 3650 \
  -out "${ROOT_CA_CRT}" -subj "/C=KR/ST=Seoul/L=Seoul/O=AONSOFT/OU=IT/CN=AONSOFT-Root-CA"

echo "### 3. Quay 서버 개인키"
openssl genrsa -out "${SERVER_KEY}" 4096

echo "### 4. Quay 서버 CSR (SAN 포함)"
openssl req -new -key "${SERVER_KEY}" -out "${SERVER_CSR}" \
  -subj "/C=KR/ST=Seoul/L=Seoul/O=AONSOFT/OU=IT/CN=${REG_URL}" \
  -addext "subjectAltName=DNS:${REG_URL}"

echo "### 5. 서버 인증서 확장 파일"
cat > "${SERVER_EXT}" <<EOF
authorityKeyIdentifier=keyid,issuer
basicConstraints=CA:FALSE
keyUsage=digitalSignature,keyEncipherment
extendedKeyUsage=serverAuth
subjectAltName=DNS:${REG_URL}
EOF

echo "### 6. Root CA로 서버 인증서 서명"
openssl x509 -req -in "${SERVER_CSR}" -CA "${ROOT_CA_CRT}" -CAkey "${ROOT_CA_KEY}" \
  -CAcreateserial -out "${SERVER_CRT}" -days 397 -sha256 -extfile "${SERVER_EXT}"

echo "### 7. 이 서버에 Root CA 신뢰 등록"
cp "${ROOT_CA_CRT}" /etc/pki/ca-trust/source/anchors/aon-root-ca.crt
update-ca-trust extract

echo "### 8. SAN 확인"
openssl x509 -in "${SERVER_CRT}" -noout -text | grep -A2 "Subject Alternative Name"
echo "### 9. 발급자 · 기간 확인"
openssl x509 -in "${SERVER_CRT}" -noout -subject -issuer -dates

echo "### 10. mirror registry 설치"
"${REG_HOME}/mirror-registry" install -v \
  --initUser "${INIT_USER}" --initPassword "${INIT_PASSWORD}" \
  --quayHostname "${QUAY_HOSTNAME}" --quayRoot "${QUAY_ROOT}" \
  --quayStorage "${QUAY_STORAGE}" \
  --sslKey "${SERVER_KEY}" --sslCert "${SERVER_CRT}"

echo "Quay URL: https://${QUAY_HOSTNAME}"
echo "Root CA (클라이언트 배포용): ${ROOT_CA_CRT}"
sh install_quay.sh
INFO Quay installed successfully, config data is stored in /opt/openshift/mirror-registry/quay
INFO Quay is available at https://init-quay.ocp.aon.cloud:8443 with credentials (admin, <Quay 암호>)
인증서 기간 주의10년인 것은 Root CA(-days 3650)뿐이고, Quay 서버 인증서는 -days 397로 약 13개월입니다. 원본 기록의 확인 명령은 다른 파일(init-quay.aon.cloud.crt, 발급자가 자기 자신)을 보고 있어서, 이 스크립트로 만든 인증서와 맞지 않습니다. 아래 명령으로 다시 확인하세요. 서버 인증서를 10년으로 쓰려면 6번의 -days를 바꿉니다. 다만 일부 클라이언트는 398일을 넘는 서버 인증서를 거부할 수 있으니 테스트로 확인합니다.
openssl x509 -in /opt/openshift/mirror-registry/quay/ca/aon-root-ca.crt -noout -subject -dates            # Root CA
openssl x509 -in /opt/openshift/mirror-registry/quay/cert.d/init-quay.ocp.aon.cloud.crt -noout -issuer -dates  # 서버

pull secret은 계정 비밀번호와 같습니다문서, 저장소, 메신저에 원문을 붙이지 않습니다. 노출됐다면 console.redhat.com에서 새로 발급받고 기존 것은 폐기합니다.

5-2. 미러 레지스트리 계정 추가

cat pull-secret.txt | jq . > pull-secret.json

echo -n 'admin:<Quay 암호>' | base64 -w0
<base64(admin:암호)>

# 방법 1) pull-secret.json 의 auths 에 직접 추가
"init-quay.ocp.aon.cloud:8443": { "auth": "<base64(admin:암호)>", "email": "<email>" }

# 방법 2) podman login 결과와 병합
jq -s '{auths: (.[0].auths + .[1].auths)}' pull-secret.json /run/user/0/containers/auth.json > merged-pull-secret.json

5-3. 도구가 읽는 위치에 복사

mkdir -p /root/.docker
cp -p merged-pull-secret.json /root/.docker/config.json
mkdir -p $XDG_RUNTIME_DIR/containers
cp -p merged-pull-secret.json $XDG_RUNTIME_DIR/containers/auth.json

5-4. install-config.yaml 에 넣을 때 (한 줄)

jq -c . merged-pull-secret.json

폐쇄망 클러스터의 install-config에는 미러 레지스트리 항목만 있으면 됩니다. Red Hat 토큰은 인터넷에서 내려받을 때만 필요합니다.
