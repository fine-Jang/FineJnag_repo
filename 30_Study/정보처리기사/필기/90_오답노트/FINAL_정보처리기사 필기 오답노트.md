## 2. 자료구조·정렬·알고리즘

- Stack: **LIFO**, 함수 복귀 주소·수식 계산·인터럽트 처리
- Queue: **FIFO**, 작업 스케줄링·대기열
- DFS: 스택 또는 재귀 사용 / BFS: 큐 사용
- 연결 리스트: 삽입·삭제는 쉽지만 포인터 추적 때문에 검색은 느릴 수 있음
- 선택 정렬: 매 회전 최솟값을 선택해 앞쪽과 교환
- 버블 정렬: 인접한 두 값을 비교해 큰 값을 뒤로 이동
- 합병 정렬·힙 정렬: 일반적으로 `O(N log N)`
- 해싱 함수: 제산법, 제곱법, 폴딩법, 숫자 분석법 등
- 개방 주소법: 해싱 **함수**가 아니라 충돌 해결 방법

- [ ] Stack과 Queue의 응용 분야를 구분한다.
- [ ] 선택·버블 정렬의 1회전 결과를 손으로 계산한다.
- [ ] 해싱 함수와 충돌 해결 방법을 구분한다.

## 3. 운영체제·프로세스·메모리

- 프로세스: PCB를 가진 실행 단위 / 스레드: 프로세스 내부의 경량 실행 단위
- HRN 우선순위: `(대기시간 + 서비스시간) / 서비스시간`, 값이 클수록 우선
- 교착상태 조건: **상호 배제, 점유와 대기, 비선점, 환형 대기**
- 은행원 알고리즘: 교착상태 **회피**
- FIFO: 가장 먼저 들어온 페이지 교체
- LRU: 가장 오래 사용되지 않은 페이지 교체
- LFU: 사용 빈도가 가장 낮은 페이지 교체
- 스래싱: 페이지 교체가 지나치게 발생해 처리보다 교체에 시간을 소비하는 상태
- 사용자 수준 스레드: 커널 모드 전환 없이 교환 가능해 오버헤드가 작음

- [ ] 교착상태 조건 4개를 말할 수 있다.
- [ ] FIFO·LRU·LFU를 구분한다.
- [ ] HRN 계산식과 우선순위 방향을 기억한다.

## 4. 데이터베이스·SQL

### 관계모델

- Degree(차수): 속성의 수
- Cardinality: 튜플의 수
- 후보키: **유일성 + 최소성**
- 슈퍼키: 유일성 만족
- 관계대수: 절차적 / 관계해석: 비절차적
- 함수 종속: `X → Y`
- BCNF: 모든 결정자가 후보키
- 카티션 프로덕트: 차수는 더하고 카디널리티는 곱함

### SQL·트랜잭션

- DDL: CREATE, ALTER, DROP
- DML: SELECT, INSERT, UPDATE, DELETE
- DCL: GRANT, REVOKE, COMMIT, ROLLBACK — 시험 분류 기준
- UPDATE 기본 형식: `UPDATE 테이블 SET 컬럼=값 WHERE 조건`
- Partially Committed: 마지막 연산은 끝났지만 DB에 최종 반영되기 전 상태
- Isolation: 병행 트랜잭션이 서로 끼어들지 않는 것처럼 수행
- 병행제어: 로킹, 타임스탬프, 다중 버전, 최적 병행수행

- [ ] Degree와 Cardinality를 즉시 구분한다.
- [ ] 후보키 조건 두 가지를 기억한다.
- [ ] 관계대수와 관계해석의 절차성을 구분한다.
- [ ] SQL 명령어 분류를 암기했다.

## 6. UML·객체지향·디자인패턴

- 스테레오 타입: `<< >>`
- 정적 다이어그램: 클래스, 객체, 컴포넌트, 배치, 패키지
- 동적 다이어그램: 시퀀스, 커뮤니케이션, 상태, 활동, 타이밍
- 유스케이스 관계: 연관, 포함, 확장, 일반화
- SRP: 클래스는 하나의 책임
- OCP: 확장에는 열려 있고 변경에는 닫힘
- LSP: 자식은 부모를 대체할 수 있어야 함
- DIP: 구체 클래스보다 추상화에 의존
- Factory Method·Abstract Factory·Prototype: 생성 패턴
- Adapter·Bridge·Composite: 구조 패턴
- Observer·Mediator: 행위 패턴

- [ ] 정적·동적 UML 다이어그램을 구분한다.
- [ ] SOLID 원칙을 한 문장씩 설명한다.
- [ ] GoF 패턴을 생성·구조·행위로 구분한다.

## 7. 보안·암호·네트워크

### 보안·암호

- 대칭키: 암호화·복호화 키 동일, AES·DES·SEED·ARIA
- 비대칭키: 공개키·개인키 사용, RSA
- Hash: 임의 길이 입력을 고정 길이 값으로 변환하는 단방향 함수

- 기밀성: 인가된 사용자만 접근
- 무결성: 인가된 사용자만 수정
- 가용성: 필요할 때 사용 가능

### 네트워크

- Repeater: 물리 계층, 신호 재생
- Bridge·Switch: 데이터링크 계층
- Router: 네트워크 계층, 최적 경로 선택
- TCP: 전송 계층, 연결형·신뢰성·흐름제어·전이중
- OSPF: 링크 상태, Dijkstra
- RIP: 거리 벡터
- CSMA/CD: 유선 Ethernet / CSMA/CA: 무선 LAN
