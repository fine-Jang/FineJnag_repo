OpenShift 4.22 폐쇄망 UPI 설치 가이드 (KVM)

KVM 호스트 위 VM으로 OCP 4.22.22 UPI 설치부터 VM 네트워크(NNCP · NAD), MTV를 이용한 vCenter VM 이관까지 실제 수행 기록 기반 절차. 스토리지(TrueNAS + democratic-csi, iSCSI 동적 할당)는 별첨 A로 분리.

대상 버전 4.22.22 (eus-4.22) · 도메인 ocp.jhw.local · 실행 환경 aon-kvm(192.168.0.92). 계정 · 암호 · 토큰 · API 키는 <...> 자리표시자. 초록 박스는 이번 실습에서 실제로 나온 결과 예시.

9-3. VDDK 이미지 (OpenVDDK · 랩 전용)

OpenVDDK는 VMware(Broadcom) 정식 VDDK가 아닌 독립 구현체(VixDiskLib 8.0.3 인터페이스 재구현, Apache 2.0, Broadcom과 무관). Red Hat 지원 대상 아님. 운영 환경은 Broadcom 정식 VDDK(VMware-vix-disklib-8.x.x.x86_64.tar.gz)로 같은 절차 수행. 읽기 전용 · HotAdd/NBDSSL/NBD 지원, SAN 전송 없음 → OCP 파드가 읽으므로 NBDSSL(ESXi 902) 사용.

별첨 B. 노드 설치 스크립트 n.sh

Bastion /root/ocp-node-install.sh → /var/www/html/ocp/n.sh(644) 복사. live ISO에서 curl -O 10.182.10.10:8080/ocp/n.sh; bash n.sh <node>. 옵션: DISK=/dev/vda, NICS="ens3 ens6".

n.sh 전체
#!/bin/bash
# OCP 4.22 (ocp.jhw.local) RHCOS node install script
# usage (live ISO console):  bash n.sh <node>
#   node: bootstrap | master01 | master02 | master03 | worker01 | worker02
# options (env): DISK=/dev/sda (default)  NICS="ens3 ens4" (default: first two NICs in PCI order)
set -u

NODE=${1:-}
case "$NODE" in
  bootstrap) IP=10.182.10.11; ROLE=bootstrap ;;
  master01)  IP=10.182.10.12; ROLE=master ;;
  master02)  IP=10.182.10.13; ROLE=master ;;
  master03)  IP=10.182.10.14; ROLE=master ;;
  worker01)  IP=10.182.10.15; ROLE=worker ;;
  worker02)  IP=10.182.10.16; ROLE=worker ;;
  *) echo "usage: bash $0 <bootstrap|master01|master02|master03|worker01|worker02>"; exit 1 ;;
esac

# re-run as root
if [ "$EUID" -ne 0 ]; then exec sudo DISK="${DISK:-}" NICS="${NICS:-}" bash "$0" "$@"; fi

DISK=${DISK:-/dev/sda}
GW=10.182.10.1
DNS=10.182.10.10
DOMAIN=ocp.jhw.local
IGN=http://10.182.10.10:8080/ocp/${ROLE}.ign

ok()   { echo -e "  [\e[32mOK\e[0m] $*"; }
fail() { echo -e "  [\e[31mFAIL\e[0m] $*"; exit 1; }

# NICs in PCI order (NIC1, NIC2 = management)
if [ -n "${NICS:-}" ]; then
  read -r -a ETH <<< "$NICS"
else
  mapfile -t ETH < <(for d in /sys/class/net/*; do
      [ -e "$d/device" ] && [ ! -e "$d/bonding" ] && echo "$(readlink -f "$d/device") $(basename "$d")"
    done | sort | awk '{print $2}')
fi

if [ "$ROLE" = bootstrap ]; then MGMT=("${ETH[0]}"); else MGMT=("${ETH[0]}" "${ETH[1]:-}"); fi
for n in "${MGMT[@]}"; do [ -n "$n" ] || fail "management NIC not found (NICs: ${ETH[*]})"; done
[ -b "$DISK" ] || fail "disk $DISK not found (check lsblk, run: DISK=/dev/vda bash n.sh $NODE)"

echo "================ OCP 4.22 node install ================"
echo " node      : $NODE.$DOMAIN"
echo " role/ign  : $ROLE  ($IGN)"
echo " ip        : $IP/24  gw $GW  dns $DNS"
if [ "$ROLE" = bootstrap ]; then echo " network   : ${MGMT[0]} (no bond)"; else echo " network   : bond0 (active-backup) = ${MGMT[0]} + ${MGMT[1]}"; fi
echo " all NICs  :"; for n in "${ETH[@]}"; do echo "     $n  $(cat /sys/class/net/$n/address)"; done
echo " disk      : $DISK  $(lsblk -dno SIZE "$DISK")   (ALL DATA WILL BE ERASED)"
echo "======================================================="
read -r -p "proceed? (y/N) " a; [ "$a" = y ] || { echo "canceled"; exit 1; }

# 1. network
echo "[1/3] network"
for c in $(nmcli -t -f UUID,TYPE con show | awk -F: '$2!="loopback"{print $1}'); do nmcli con del "$c" >/dev/null 2>&1; done
for n in "${ETH[@]}"; do ip addr flush dev "$n" 2>/dev/null; done

if [ "$ROLE" = bootstrap ]; then
  nmcli con add type ethernet ifname "${MGMT[0]}" con-name mgmt \
    ipv4.method manual ipv4.addresses "$IP/24" ipv4.gateway "$GW" \
    ipv4.dns "$DNS" ipv4.dns-search "$DOMAIN" ipv6.method disabled >/dev/null || fail "nmcli add mgmt"
  nmcli con up mgmt >/dev/null || fail "nmcli up mgmt"
else
  nmcli con add type bond ifname bond0 con-name bond0 \
    bond.options "mode=active-backup,miimon=100" \
    ipv4.method manual ipv4.addresses "$IP/24" ipv4.gateway "$GW" \
    ipv4.dns "$DNS" ipv4.dns-search "$DOMAIN" ipv6.method disabled >/dev/null || fail "nmcli add bond0"
  for n in "${MGMT[@]}"; do
    nmcli con add type ethernet ifname "$n" master bond0 con-name "bond0-$n" >/dev/null || fail "nmcli add bond0-$n"
  done
  nmcli con up bond0 >/dev/null || fail "nmcli up bond0"
fi
ok "connection up"; sleep 3

# 2. checks
echo "[2/3] checks"
ip -br -4 addr | grep -q "$IP/24" && ok "ip $IP/24" || fail "ip not assigned"
[ "$ROLE" != bootstrap ] && grep -E "Currently Active Slave|MII Status" /proc/net/bonding/bond0 | head -2 | sed 's/^/        /'
ping -c2 -W2 "$DNS" >/dev/null && ok "ping bastion $DNS" || fail "ping bastion $DNS"
getent hosts "api-int.$DOMAIN" >/dev/null && ok "dns api-int.$DOMAIN -> $(getent hosts api-int.$DOMAIN | awk '{print $1}')" || fail "dns api-int.$DOMAIN"
code=$(curl -s -o /dev/null -w "%{http_code}" "$IGN"); [ "$code" = 200 ] && ok "ignition $IGN (200)" || fail "ignition http $code"

# 3. install
echo "[3/3] coreos-installer -> $DISK"
coreos-installer install "$DISK" --ignition-url "$IGN" --insecure-ignition --copy-network || fail "coreos-installer"
ok "install complete"
echo "reboot in 10s (Ctrl+C to cancel)"; sleep 10; reboot
